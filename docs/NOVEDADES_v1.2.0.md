# SIGE v1.2.0 — Novedades

Versión con mejoras de accesibilidad, apariencia y seguridad sobre la 1.0.0 (apariencia y accesibilidad) (web, escritorio y Aula virtual).

## Accesibilidad y apariencia
- **Menú del ojo (barra superior):** agrupa los modos de visión para daltonismo (protanopía, deuteranopía, tritanopía) y alto contraste.
- **Modo claro / oscuro:** botón de brillo en la barra superior, en la web, el Aula virtual y el ejecutable.
- **Iconos** en cada apartado del menú, en el ejecutable y en la web (incluido el icono de la aplicación).
- **Botones dinámicos:** efectos suaves al pasar el cursor y al pulsar, en web y escritorio.
- **Estaciones del año automáticas:** fondos, colores y animaciones de primavera, verano, otoño e invierno, que cambian solos 7 días antes de cada estación.
- **Panel principal animado:** entrada suave, ilustración en movimiento y tarjetas que se elevan; en escritorio, encabezado con círculos flotantes.
- **Animaciones:** opción «Siempre activas» para verlas aunque el sistema pida reducir movimiento.
- **Pantalla de inicio de sesión** con animación (GIF).

## Mejoras de uso
- «Reporte de asistencia» con diseño alineado.
- El botón de cerrar servidor está en el menú plegable.
- **Aula virtual → «Volver a SIGE»** mantiene la sesión abierta.

## Calidad y documentación
- Pruebas automáticas nuevas para visión, tema, iconos, estaciones y movimiento.
- `docs/CREDITOS_Y_ORIGINALIDAD.md`: revisión de proyectos similares y créditos.
- Seguimiento del avance en `docs/PROGRESO.md`.

## Notas
- Las cookies de preferencias (`sige_vision`, `sige_tema`, `sige_estacion`, `sige_mov`) no guardan datos personales.
- Si el sistema tiene desactivadas las animaciones, la web las oculta salvo que elijas «Siempre activas».
